# إعداد Google Cloud

الربط لا يكتمل داخل الكود وحده. التطبيق يستخدم `AuthorizationClient` من Play Services، والنطاقات:

- `https://www.googleapis.com/auth/spreadsheets`
- `https://www.googleapis.com/auth/drive.readonly`

`drive.readonly` مطلوب لأن اختيار الملفات يعرض جداول الحساب الموجودة، بما فيها المشتركة عبر `supportsAllDrives`. نطاق `drive.file` لا يعرض تلك الملفات، لذلك لم يُستخدم. لا يوجد Client Secret ولا مفتاح Service Account ولا refresh token مخزّن. رمز الوصول يبقى في الذاكرة فقط، ومعرّف الهوية ليس بديلاً عنه.

اختيار الحساب ليس نجاحاً. الحالات منفصلة: اختيار الحساب، صدور رمز الوصول، قراءة الملفات، اختيار أوراق الدورة، ثم تنزيل نسخة محلية. فشل 401 أو 403 أو الشبكة لا يُعرض كقائمة ملفات فارغة. النتيجة والرمز التشخيصي يظهران في شاشة الإعدادات، ويُنسخ الرمز بعد حذف أي `Bearer` أو `ya29`.

## الخطوات على حساب Google

1. افتح Google Cloud Console وأنشئ مشروعاً أو اختر الموجود.
2. فعّل Google Sheets API وGoogle Drive API.
3. اضبط شاشة الموافقة. في وضع Testing أضف حساب الهاتف كمستخدم اختبار. النطاقات الحساسة `spreadsheets` و`drive.readonly` تبقى للاختبار حتى تطلب Google مراجعة التطبيق إن نُشر خارج مستخدمي الاختبار.
4. أنشئ OAuth Client من نوع Android.
5. اسم الحزمة: `cloud.lork.audit`.
6. ضع SHA-1 لشهادة الملف الذي سيُثبَّت، لا بصمة قديمة.

## بصمة هذا البناء

الملف المبني هنا debug. لا يوجد مفتاح إصدار في المستودع، لذلك لا يحدّث هذا الملف تطبيقاً موقّعاً بغيره.

SHA-1 لشهادة APK هذا البناء:

```
CA:E8:33:56:47:96:F4:D8:54:C8:16:29:19:90:62:28:0F:25:E2:6F
```

هذه البصمة لشهادة debug التي أنشأها هذا البناء في `~/.android/debug.keystore`. البناء على GitHub Actions ينشئ شهادة debug أخرى على المشغّل، فبصمتها مختلفة. سجّل بصمة الملف الذي تثبّته:

```
apksigner verify --print-certs app-debug.apk
```

أو من المفتاح المستخدم:

```
keytool -list -v -keystore debug.keystore -alias androiddebugkey -storepass android
```

ميّز ثلاث شهادات: debug المحلي، debug على جهاز المطوّر، وشهادة Play App Signing إن نُشر التطبيق لاحقاً. كل واحدة تحتاج عميلاً أو بصمة في عميل Android نفسه.

لم يُختبر تسجيل دخول حقيقي ولا استدعاء Sheets حي في هذا البناء. مسار الإلغاء وفشل التفويض وتوقف النشاط وتعدد صفحات Drive مغطى باختبارات محاكاة في المحرك.
