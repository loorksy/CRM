# إصلاح اختيار ملفات الدورة — 1.0.5

كانت بطاقات المصادر تغيّر الدور فقط، ثم تُعرض ملفات Drive أسفل الصفحة، وتُضاف أوراق الملف بعد أول 20 ملفاً. لذلك لم يظهر أثر النقر في موضعه. كما كان فشل طلب أوراق Sheets يُحوّل إلى قائمة فارغة، مع إمكان بقاء أوراق ملف سابق ظاهرة أثناء تحميل ملف جديد.

## السلوك الحالي

- الضغط على بطاقة الإدارة أو الوكيل أو معلومات المستخدمين يفتح نافذة اختيار خاصة بذلك الدور.
- الخطوة الأولى تعرض كل الملفات المحمّلة في قائمة قابلة للبحث والتمرير؛ لا يوجد قطع عند أول 20 نتيجة.
- الضغط على ملف ينقل النافذة فوراً إلى خطوة الأوراق مع مؤشر تحميل. اختيار الورقة يربط الملف والورقة بالدور المقصود ويحفظهما محلياً.
- تعرض البطاقة اسم الملف والورقة بعد الاختيار، ويعودان عند تحميل الدورة. إلغاء النافذة لا يبدّل المصدر.
- لكل طلب سياق حساب ودورة ودور ورقم متغير؛ نتائج الملفات أو الأوراق السابقة تُرفض بعد التبديل أو الإلغاء. لا يمكن اختيار عنوان ورقة من ملف سابق أثناء التحميل.
- تظهر أخطاء Google وإعادة المحاولة داخل النافذة. نجاح قائمة Drive لا يعني نجاح Sheets: تعطيل API أو نقص الصلاحيات أو انتهاء التفويض تظهر بأسباب مستقلة وآمنة.
- اقتراح أعمدة معلومات المستخدمين لا يكتب فوق تعديل يدوي أُجري أثناء انتظار العناوين.

أسماء الملفات أُضيفت إلى JSON المصادر بقيم افتراضية فارغة. لا يتغير مخطط Room، وتظل اللقطات مرتبطة بمعرّفات الملفات والأوراق؛ تغيير اسم الملف وحده لا يبطلها.

## التحقق

نجح:

```sh
./gradlew :engine:test :app:testDebugUnitTest :app:assembleDebug :app:assembleDebugAndroidTest --no-daemon
```

النتيجة: 55 اختباراً بلا فشل أو أخطاء أو تخطٍّ:

- 43 اختبار محرك، منها 10 اختبارات اختيار جديدة تشمل مجموعة اصطناعية من 713 ملفاً، الانتقال إلى الأوراق، الإلغاء والعودة، رفض اختيار ورقة قديمة، وتجاهل ردود طلب سابق عبر الحساب أو الدورة أو الدور.
- 12 اختبار تطبيق: 3 لحفظ المصادر وأسمائها وتوافق JSON القديم، و9 لأخطاء Google، منها نجاح Drive مع رفض Sheets، وتعطيل API، ونقص النطاقات، وعدم إظهار نصوص أخطاء قد تحتوي معلومات حساسة.

بُني APK التطبيق وAPK الاختبار. لم يُنفّذ اختبار جهاز متصل أو حساب Google حقيقي في هذه المتابعة؛ الصور الواردة من المستخدم تثبت ظهور قائمة الملفات في إصدار سابق، ولا تُعد اختباراً للبناء الجديد.
