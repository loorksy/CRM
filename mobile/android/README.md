# تدقيق لورك — تطبيق أندرويد مستقل

المصدر الحالي: **1.0.5**، الحزمة `cloud.lork.audit`.

**[تحميل APK الإصدار 1.0.5 — إصلاح اختيار الملفات](dist/cloud.lork.audit-1.0.5-test.apk)**

شهادة 1.0.5 تطابق شهادة [نسخة الفحص 1.0.4](dist/cloud.lork.audit-1.0.4-test.apk)، ورمز الإصدار أعلى منها. أما [APK القديم 1.0.2](dist/cloud.lork.audit-1.0.2.apk) فشهادته مختلفة وبقي محفوظاً دون تغيير.

التطبيق عربي ويعمل دون خادم خاص. يختار المستخدم دورة مالية وأوراقها؛ زر التدقيق يزامن البيانات ثم يطبّق الرواتب والحالات والنسخ والألوان في Google Sheets. توجد معاينة محلية مستقلة دون كتابة، وبحث وتدقيق انتقائي في ورقة هدف. الإرسال من فقاعة تحتوي محرر الرسائل والعدد والسرعة والتحكم بالطابور فوق محادثة واتساب المفتوحة.

## إصلاح اختيار الملفات

اضغط بطاقة الإدارة أو الوكيل أو معلومات المستخدمين؛ تظهر نافذة الملفات، ثم نافذة أوراق الملف الذي تختاره. يُحفظ اختيار الورقة للدور المحدد وتعرض بطاقته اسم الملف والورقة. أخطاء القراءة وإعادة المحاولة تظهر داخل النافذة. [تفاصيل الإصلاح والتحقق](docs/FILE_SELECTION_FIX.md).
